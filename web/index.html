tmux·pocket

Tes sessions tmux et tes agents de code (pi, claude, codex…) dans ta poche : aperçu en direct de chaque fenêtre, TUI rendu fidèlement avec un défilement natif, chat pi natif, WeeChat au doigt.

Démo : fonctionne sans serveur. Tape pi ou tmux ls dans le shell.

Serveur réel : cd bridge && npm i && npm start, puis http://127.0.0.1:8022.
