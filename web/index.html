tmux pocket

Prototype iPhone : gestionnaire de sessions/fenêtres tmux via SSH + chat natif avec les agents (pi, claude, codex…).

Démo (simulation) fonctionne sans serveur : fenêtres pi, claude, htop, logs, shell. Tape pi ou tmux ls dans le shell.

Serveur réel : cd tmux-pocket/bridge && npm i && npm start puis ouvre http://127.0.0.1:8022.
